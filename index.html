Apply against stock Hermes

From the root of a checkout of the base commit 71d34bad10:
git apply compressorpatch.patch

If an earlier hermes-compaction patch is applied, revert first (git checkout -- agent/context_compressor.py agent/micro_compaction.py agent/agent_init.py) and apply this one instead — it supersedes v3.3/v3.4.1.

Recommended compression settings

The patch is behavior-neutral by default (defaults = stock). To run the tuned stack (same band this chain was developed in: a 200k window breathing 80–135k), add to config.yaml:

compression:
  micro_compact: true
  micro_compact_every_n_turns: 6            # cadence arms ~2.8x/runway; each pass buys ~2.5 turns
  micro_compact_min_reclaim_tokens: 2700    # v3.4.7 floor: absorb must measure >=2.7k reclaim to commit; windows whose best-case reclaim can't clear it skip pre-generation (free)
  micro_compact_max_occupancy_pct: 60       # v3.4.6: skip micros at/above 60% of resolved window (fold territory); 0 = off
  context_timeout_seconds: 240              # fold watchdog headroom under the 300s aux budget
  micro_compact_defrag_threshold_tokens: 20000  # leave high: memo ceiling (3000) governs first
